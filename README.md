# Gurmukhi-Guide
Developed and submitted an app called “The Gurmukhi Guide”, an offline SwiftUI learning app designed to make learning the Gurmukhi script more accessible and engaging. The app features interactive alphabet tracing, quizzes, number learning, and educational content about Punjabi language and culture. Built independently using Swift.
